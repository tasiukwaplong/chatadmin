🛠️ Developer Implementation Guide for 02 Innovation Lab

Key technical stack and integration workflow to implement these WhatsApp chatbot scenarios:

1. WhatsApp Cloud API Layer

Configure webhook listener endpoint (Node.js Express / Python FastAPI) registered on Meta for Developers. Verify webhook token and handle inbound message events.

2. NLP & Vision OCR Parser

Use LLM (Claude 3.5 / OpenAI GPT-4o / Llama 3) with Structured Outputs JSON mode to extract currency amounts, categories, counterparties, and payment terms. Pass receipts through Vision API.

3. Financial Ledger & Cron Daemon

Relational DB (MySQL / PostgreSQL) storing transactions, debts, and reminders. Cron worker runs scheduled check-ins and dispatches WhatsApp alert templates.
