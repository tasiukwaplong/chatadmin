SCHEDULED_PAYABLES.sql
CREATE TABLE recurring_payables ( id INT AUTO_INCREMENT PRIMARY KEY, company_id VARCHAR(50) NOT NULL, title VARCHAR(150) NOT NULL, amount DECIMAL(12,2) NOT NULL, frequency ENUM('ONCE', 'MONTHLY', 'QUARTERLY', 'ANNUAL') DEFAULT 'MONTHLY', due_date DATE NOT NULL, alert_days_before INT DEFAULT 5, status ENUM('PENDING', 'PAID', 'SKIPPED') DEFAULT 'PENDING' ); -- Query upcoming payments due in next 7 days SELECT * FROM recurring_payables WHERE status = 'PENDING' AND due_date BETWEEN CURDATE() AND DATE_ADD(CURDATE(), INTERVAL 7 DAY);
AUTOMATION_SPEC.md
Execution Logic: 1. Daily Daemon at 08:00 AM checks `recurring_payables` where `due_date <= CURDATE() + alert_days_before`. 2. Consolidates all pending items into a single WhatsApp notification message. 3. Automatically attaches deep-link with single-sign-on token to `chatadmin.02innovationslab.com/reminder/all/`. 4. If marked as paid via bot or portal, an `EXPENSE` transaction is automatically generated in the general ledger.
